# BOM 轻量级 Web 系统实施计划（确认版 v1.0）

## 1. 计划目标

依据 [项目方案.md](项目方案.md) 的 34 项已确认决策，完成一套在局域网 Windows 主机运行的 BOM Web 系统，并使用 [BOM物料清单管理(1).xlsm](<../../data/migration/BOM物料清单管理(1).xlsm>) 一次性初始化首版数据库。

本计划是开发、测试、迁移和验收的执行基线。需求材料存在冲突时，以 [项目方案.md](项目方案.md) 的已确认结论为准。

## 2. 首期范围

### 包含

- 原材料、半成品、单元、整机四类对象管理。
- 原材料自组装、受控跨层 BOM、树形构成和反向引用。
- 系统物料编码规则、版本、推荐编码和受控规则覆盖导入。
- 原材料日常 Excel 批量导入及相似物料确认。
- 同类型选配组和 BOM 位置替换。
- 技术 BOM、生产 BOM、单个/批量 Excel 导出。
- 1–5 个同类型对象的 BOM 差异矩阵。
- 产品机型归属、三态管理、复制、软删除和版本追溯。
- 批量 BOM 替换、调量、增加、删除。
- 不可修改/删除的变更审计和 Excel 导出。
- 基础账户、三个固定角色和账户启停。
- 历史 xlsm 一次性初始化迁移与对账。
- Windows 单机部署、每日备份和恢复文档。

### 不包含

- 半成品嵌套半成品。
- 半成品、单元、整机及 BOM 关系的日常 Excel 批量导入。
- 审批流、主动消息推送、复杂权限矩阵。
- 复杂 BOM 关系图可视化。
- 损耗率、工位、位号、生效日期等制造执行字段。
- 多机集群、高并发、互联网依赖或移动客户端。

## 3. 技术基线

- 前端：Vue 3、TypeScript、Vite、Element Plus。
- 后端：Python 3.12、FastAPI、Pydantic。
- 数据层：SQLAlchemy 2、Alembic、SQLite，开启 WAL 和外键。
- Excel：openpyxl；历史 xlsm 只读取单元格，不执行 VBA。
- 相似度：Unicode NFKC 规范化、RapidFuzz、可配置 95%/50% 阈值。
- 测试：pytest、API 集成测试、Playwright 关键路径测试。
- 部署：前后端构建后由同一 Windows 主机提供服务，浏览器访问。

## 4. 数据模型工作包

### 4.1 物料与版本

`item` 至少包含：

- 类型：原材料、半成品、单元、整机。
- 系统物料编码、编码主体、数值版本、原始版本显示值。
- 可选辅助索引码。
- 名称、规格型号、单位、备注、上一版本名称、发票名称、材料属性、变更记录说明。
- 原材料来源属性：外购、外协、自制。
- 是否需要组装。
- 半成品/单元/整机状态：有效、试产、停用。
- 版本系列、复制来源、软删除标志和时间戳。

关键约束：

- 系统物料完整编码全局唯一，软删除后仍占用。
- 同一版本系列内版本号不可重复。
- 原材料不使用有效/试产/停用三态。
- 外购/外协无组成时可作为叶子原材料；自制新建必须有组成；是否需要组装由实际 BOM 关系派生；外协/自制已有组成时改外购前必须先清空组成。

### 4.2 BOM 关系

`bom_line` 保存父项、子项、定点数量、显示顺序、行备注、选配组和当前选中项。

父子白名单：

| 父项 | 子项 |
|------|------|
| 原材料 | 原材料 |
| 半成品 | 原材料 |
| 单元 | 半成品、原材料 |
| 整机 | 单元、半成品、原材料 |

同一父项下同一子物料只有一行，重复添加时合并数量。所有写入口共用同一 BOM 领域服务，执行类型、正数量、停用状态、直接环和间接环校验。

### 4.3 配套实体

- 编码：`code_rule`、`code_rule_segment`、`code_rule_snapshot`、`code_allocation`。
- 选配：`alternative_group`、`alternative_member`。
- 导入：`import_batch`、`import_row`、`import_decision`。
- 审计：`audit_event`、`audit_change`。
- 账户：`user`、固定 `role`。
- 后台文件任务：`export_job`。

产品归属和反向引用以 BOM 图实时计算；如实际性能需要，可增加能够随时重建的缓存，不把缓存作为事实源。

## 5. 分阶段实施

### 阶段 0：需求基线与黄金样本

任务：

1. 将已确认业务规则整理成字段字典、状态表和父子白名单。
2. 从参考文件选取至少一个整机、一个单元、一个半成品和一个组装原材料作为黄金样本。
3. 固化技术 BOM 12 列、生产 BOM 11 列和原材料导入模板。
4. 形成历史 xlsm 字段映射及异常分类清单。

交付物：字段字典、规则矩阵、黄金 BOM 样本、迁移映射。

退出条件：编码、数量、层级、选配和输出口径均能用样本说明，无业务未决项。

### 阶段 1：工程底座、账户与运维

任务：

1. 建立前后端工程、环境配置和统一错误响应。
2. 建立 Alembic 迁移和 SQLite 初始化流程。
3. 完成基础登录、账户启停及管理员/维护/查看三个角色。
4. 完成应用日志、健康检查、Windows 服务脚本。
5. 完成 SQLite 安全备份、可配置保留期（默认 30 份）和恢复脚本。

交付物：可启动的空系统、初始管理员、数据库初始化/备份/恢复工具。

退出条件：三类角色权限正确；服务重启后数据保持；备份能够在独立目录恢复并通过完整性检查。

### 阶段 2：物料、编码、版本与原材料导入

任务：

1. 完成统一物料模型和四类独立页面。
2. 初始化编码规则；完成规则页面、逐级下拉、最大值/下一号提示。
3. 完成编码规则 Excel 差异预览、快照、事务覆盖和回滚。
4. 完成新版本/新物料两类复制及软删除/恢复。
5. 完成名称规格规范化、红黄相似提醒和二次确认。
6. 完成原材料 Excel 暂存预览、分批勾选、原子提交和错误报告。

交付物：物料中心、编码规则中心、原材料导入中心。

退出条件：

- 完整编码重复在所有入口均被拒绝。
- 历史 `.0/.1` 保持原样，新版本正确生成两位尾号。
- 高相似物料可在确认后创建，并记录确认事实。
- 导入所选行任一失败时，该次所选行全部回滚。

### 阶段 3：BOM 核心与追溯

任务：

1. 完成 BOM 新增、编辑、拖拽排序、数量和行备注。
2. 完成父子类型白名单和环路检测。
3. 完成原材料自组装、外购/外协叶子兼容、自制强制组成及组装标志自动同步规则。
4. 完成树形构成、直接父项、全部上层引用和产品机型归属。
5. 完成有效/试产/停用状态规则、引用警告和删除保护。

交付物：BOM 编辑器、构成树、反向引用树、产品归属视图。

退出条件：所有非法父子组合和直接/间接环均被拒绝；停用对象不能新增引用但历史结构不变；产品归属能下钻到引用路径。

### 阶段 4：选配、BOM 输出与模块比较

任务：

1. 完成同类型选配组的创建/编辑、默认项、备选项、引用保护和 BOM 位置替换。
2. 完成技术 BOM 路径展开和 12 列预览/Excel。
3. 完成生产 BOM 叶子展开、路径定点数量相乘、按完整编码汇总和 11 列 Excel。
4. 完成多对象独立 Excel 后打包 ZIP。
5. 完成 1–5 对象差异矩阵、颜色提示、路径下钻和 Excel 导出。

交付物：选配中心、BOM 预览导出、批量导出、模块比较。

退出条件：黄金 BOM 的层级、顺序、物料和数量 100% 一致；选配只计算当前项；小数累计无浮点误差。

### 阶段 5：批量维护与不可变审计

任务：

1. 完成按物料反查多个 BOM。
2. 完成批量替换、调量、增加和删除的影响预览。
3. 强制变更原因并按批次提交。
4. 完成追加式审计、前后值、对象时间线、近期变更和 Excel 导出。
5. 禁止所有账户修改或删除审计记录。

交付物：批量 BOM 维护、审计中心、近期变更工作台。

退出条件：每项受控变更都能从批次下钻到对象和字段前后值；新版本不会自动改变已有 BOM。

### 阶段 6：历史初始化迁移

任务：

1. 以只读方式解析历史 xlsm 的原材料、半成品、单元、整机和组成关系。
2. 写入迁移暂存库，生成重码、孤儿、字段错位、非法关系和无法识别引用报告。
3. 提供对冲突记录的修正、跳过和映射决策。
4. 确认后原子写入正式首版数据库，保留来源行号和迁移批次。
5. 对实体数量、关系数量、编码唯一性和黄金 BOM 做迁移前后对账。
6. 原始 xlsm 不修改，归档为迁移凭证。

交付物：迁移脚本、异常报告、确认记录、首版数据库、对账报告。

退出条件：所有异常均有明确处置；正式库无非法关系和环路；黄金 BOM 对账通过。

### 阶段 7：UAT 与上线

任务：

1. 执行完整回归、浏览器关键流程和恢复演练。
2. 使用首版数据库完成用户验收。
3. 部署到局域网 Windows 主机并注册后台服务。
4. 配置每日备份、日志目录和磁盘空间检查。
5. 交付安装、操作、备份恢复和故障处理文档。

交付物：上线系统、验收报告、部署包和运维文档。

退出条件：验收用例全部通过；备份可恢复；其他局域网电脑可通过浏览器访问；系统重启自动恢复服务。

## 6. 核心验收矩阵

| 需求域 | 验收标准 |
|--------|----------|
| 编码 | 系统物料编码全局唯一；逐级下拉和推荐编码正确；历史尾号不改写 |
| 相似检查 | 四类统一红黄提示；红色需二次确认但可创建；编码重复不可绕过 |
| 原材料组装 | 外购/外协无组成可作为叶子并维护档案；自制新建强制有组成；新增/移除组成自动同步组装标志；原材料递归无环；有组成的外协/自制改外购前必须先清空 |
| 层级 | 仅允许已确认父子白名单；半成品不能包含半成品 |
| 技术 BOM | 路径完整、不合并、数量为本层用量、12 列、人工顺序正确 |
| 生产 BOM | 只含叶子原材料、路径数量相乘、完整编码汇总、11 列、首次顺序正确 |
| 选配 | 同类型、一默认多备选、已建组可编辑、当前选中成员不可直接移出、每位置只选一个、输出只计算当前项 |
| 比较 | 1–5 个同类型对象，矩阵数量、颜色、路径和 Excel 一致 |
| 反向追溯 | 能从任意物料定位全部父项和有效/试产/停用整机路径 |
| 状态与删除 | 停用不允许新引用；已有引用保留；有引用禁止删除；软删除可恢复 |
| 版本 | 新版本不自动升级现有 BOM；显式替换有影响预览和审计 |
| 批量维护 | 替换/调量/增加/删除均需原因、原子提交和批次日志 |
| 审计 | 操作人、时间、原因、前后值完整；任何账户均不能修改删除 |
| 迁移 | 异常全部确认；实体/关系数量及黄金 BOM 对账通过；原文件不改动 |
| 运维 | 服务自启动；每日备份；恢复演练成功；SQLite 不置于共享目录 |

## 7. 测试策略

- 单元测试：编码解析/分配、文本规范化、相似阈值、父子白名单、环路、定点数量、状态和删除规则。
- 集成测试：API 与真实 SQLite 事务、规则覆盖回滚、导入原子性、审计追加性。
- 黄金样本测试：技术 BOM、生产 BOM、选配、版本替换和产品归属。
- 浏览器测试：登录、编码引导、导入预览、BOM 拖拽、批量维护、导出和比较。
- 迁移测试：重复执行预检不改变原文件；确认前不写正式库；对账结果可复现。
- 运维测试：服务重启、在线备份、恢复、磁盘空间不足和损坏数据库告警。

## 8. 实施顺序与依赖

```text
阶段 0 需求/样本基线
  └─阶段 1 工程与运维底座
      └─阶段 2 物料/编码/导入
          └─阶段 3 BOM 核心/追溯
              ├─阶段 4 选配/输出/比较
              └─阶段 5 批量维护/审计
                    └─阶段 6 初始化迁移
                        └─阶段 7 UAT/上线
```

阶段 4 和阶段 5 可在 BOM 核心稳定后并行开发，但必须在初始化迁移和最终验收前共同完成。

## 9. 变更控制

- 本计划确认后，新需求先记录为变更项，评估对数据模型、迁移、输出和验收的影响。
- 会改变已确认业务口径的事项必须更新 [项目方案.md](项目方案.md) 和本计划后再实施。
- UI 文案、列宽、颜色等不改变业务结果的细节，可在 UAT 中调整。
- `superpower` 技能不在本项目规划与后续实施依赖中。
