# BOM 系统特殊需求与移植指南

更新时间：2026-09-16。适用基线：V1.2、四次需求及“移除最后备选 / 子物料搜索上下文”修复。

本文面向接手开发、ERP/PLM 集成及替换现有技术栈的人员，是业务语义和移植验收入口，不是安装教程，也不新增需求。“普通 BOM”仅指以物料主档、父子组成、数量展开为核心的基础实现，不表示其他产品一定不具备以下能力。

## 1. 一句话理解这个系统

这是面向水质分析仪产品族的轻量物料与 BOM 管理系统：**共享组件组成 + 按具体引用路径继承或覆盖的选配 + 独立的未正式原材料生命周期 + 网页与 Excel 不同的展示规则**。

它不是单纯把 Excel 父子表搬到数据库。最重要的移植对象是“在某台整机、某条引用路径上实际使用哪个组件”，而不是一张全局替代料表。

首批按单人操作设计，随后增加固定角色，2026-10-09 新增财务只读角色。重点是编码、组合、选配、用量、追溯和操作可靠性，不是完整 ERP：本轮不扩展库存、采购订单、工艺路线、成本核算、审批流、部门级数据隔离或分布式架构。

## 2. 与基础 BOM 的关键差异

| 维度 | 基础实现容易采用的方式 | 本系统必须保留的特殊规则 |
| --- | --- | --- |
| 物料层级 | 任意物料互相挂接或固定三级树 | 四种业务类型和受控父子矩阵；原材料可组合，半成品可嵌套 |
| 组合半成品 | 手工打标签或独立物料类型 | 由直接组成自动派生，属于半成品类型 |
| 替代料 | 全局替代组，一处切换全局生效 | 按所属物料及组成行路径保存配置，支持继承、自定义、固定组件 |
| 用量 | 所有展开行求和，或按概率加权 | 只计算实际选用路径；市场占比、备选行均不增加实际用量 |
| 重复检查 | 全树去重或自动合并 | 同一实际父项直接重复禁止，不同路径、不同层级允许重复 |
| 未正式物料 | 在正式物料上改状态 | 独立 `99.*` 序列；转正式新建物料，原记录永久封存、双向追溯 |
| 编码 | 前端拼号或全局自增 | 按类型、大类、小类及格式规则选码，后端查重、建议号与事务取号 |
| 删除 | 永久占码或仅软删除 | 正式物料可受保护地彻底删除并释放编码；身份和历史不能随复用编码串联 |
| 技术/生产 BOM | 一张报表换个名称 | 技术表保留引用路径；生产用量逐层相乘，展开边界可选 |
| 网页/Excel | 一套表格直接导出 | 网页备选按行和树展示，Excel 备选横向列；生产 Excel 有选配签名分组 |
| 机型归属 | 人工填写产品归属 | 沿实际选用路径反向计算，排除备用路径、停用整机等 |
| 历史 | 保存一段“变更说明”字段 | 追加式前后值审计；主档变化和下级组成变化可追溯，手工说明保留 |
| 搜索导航 | 只搜索已加载页，点击编码离开编辑页 | 全库补全、分页续载、快速查看弹窗、新标签编辑，保持编辑上下文 |

## 3. 领域模型与层级边界

### 3.1 四类物料共用主档，不等于允许任意嵌套

| 父项类型 | 允许直接子项 |
| --- | --- |
| 原材料 `material` | 原材料 |
| 半成品 `semi_finished` | 半成品、原材料 |
| 单元 `unit` | 半成品、原材料 |
| 整机 `machine` | 单元、半成品、原材料 |

- 单元不能直接套单元，整机不能直接套整机；半成品不能包含单元或整机。
- 半成品只要直接包含至少一个半成品，就自动成为“组合半成品”；移除最后一个直接半成品后取消标签。不能仅根据更深后代或人工复选框判定。
- 原材料的外购、外协、自制是来源属性，不决定它是否有组成。外购/外协原材料没有组成时仍允许保存档案、按普通叶子物料使用。
- 原材料有没有下级、是否展开，都以实际 BOM 行为依据；不强制先创建子项才能改规格或备注。
- 业务不人为限制半成品嵌套层数，但必须防环。现有解析器另有 50 层、20,000 节点保护，移植时可用等价保护，不能静默截断结果。

### 3.2 主档与组成行必须分离

物料主档包含编码、名称、规格型号、单位、物料备注、上一版本名称、发票名称、材料属性、状态、来源、关键器件码、历史物料号等；整机另有机型。组成行持有父项、子项、数量、顺序、行备注。

修改物料名称、规格、备注后，使用它的 BOM 应显示新档案，不应在每条组成中保存一份不更新的副本。审计历史则必须保留操作当时的编码名称快照。

原材料状态为在用/停用，与来源独立；半成品、单元和整机为试制/在用/停用。默认列表隐藏停用，但能筛选查看。停用不自动拆掉既有组成，仍可查看导出并提示风险；不能新增为组成或选配候选。

## 4. 最重要的差异：引用路径选配

### 4.1 配置作用域与继承

配置键不是“组件编码”，而是 **所属物料 ID + 从所属物料开始的组成行 ID 路径**。路径必须用稳定的组成行身份表达，不能用显示顺序、名称或可能复用的编码拼接。

- 没有本地记录：继承下级最新配置；没有下级配置时使用基础组成。
- 本路径自定义：保存当时的候选、占比和当前选用项，后续不跟随下级选配变化。
- 本路径禁用：固定一个组件，不显示备用、不跟随下级切换；不是删除整条组成。
- 解析时从根向下，当前根物料的路径覆盖优先于中间层及下级配置；同一子组件的其他引用路径不受影响。
- 自定义冻结的是选配内容，不是整个组件档案：数量、行备注、主档信息和组件自身组成仍随其源数据更新。

示例：半成品 S 的原材料候选是 A/B，默认 A；整机 M1 与 M2 都使用 S。M1 对 `M1→S→该组成行` 选 B，M2 继续继承 A。不能通过修改 S 的全局选中项实现 M1 的专属选择，否则会误改 M2。

### 4.2 候选校验与数量

- 候选必须与当前组件同类型；普通半成品和组合半成品是同类型。整机本身不作为候选类型。
- 2026-10-08 起，有下级组成的原材料也支持路径选配：在原材料的“BOM 编辑 → 完整层级结构”点击“配置选配”。原材料内部只能选配同类型原材料，沿用确认保存、数量不变、同层不重复、防环与变更记录规则。上级可以继承，也可覆盖原材料内部的具体路径，不影响其他引用；无下级原材料没有可配置的组成行。
- 技术/生产 BOM 是否展开原材料仍由现有开关控制：不展开时按原材料整体计量，展开后仅计算当前选用的下级组成，备选不计入用量。
- 排除未正式、封存、停用或已删除对象，检查所有实际/备用展开路径的环路。
- 当前项包含在候选中；有备选时至少两个不同候选。占比合计 100%，最多两位小数，允许 0%。
- 默认平均分配占比；修改一项后其余按原比例分摊，舍入差需要明确分配。历史 X 组迁移和界面编辑的尾差分配顺序可不同，但总和必须精确为 100%。
- 占比仅为展示信息，与当前选用独立，不参与数量计算。
- 切换选用不改变原行数量、顺序和备注。选中候选只修改编辑草稿，用户确认保存后才生效。
- 同一有效父项下已实际选用目标组件时，禁止重复、禁止自动合并；组件只存在于更深层级则允许。
- 下级改配置也必须检查受影响上级的有效结果，不能只检查被编辑的那一层。

### 4.3 移除最后备选、路径失效与复制

- 用户移除备选至只剩当前选用项时，允许保存为无备选，不再报“至少两个组件”。取消保存仍保持原配置。
- 对直接组成：保留当前实际选用组件和数量，清除本地选配；如果原备选已成为主选，不能退回旧基础组件。
- 对深层组成：固定本物料的该路径组件以阻止下级备选重新继承，不修改共享下级 BOM。这里“无备选”仍可能需要一条固定覆盖记录。
- 替换祖先、移除基础组成导致下层专属路径失效时，保存前列出影响，确认后同事务清除并记录历史；切回旧组件不自动恢复已清除配置。
- 改数量、排序、行备注不能误删路径配置。
- 复制物料或新版本时复制源物料自身保存的路径配置，并重映射复制后的组成行 ID；不复制其他上级对源物料设置的专属配置。继承关系继续继承，复制出的自定义独立维护。

## 5. 正式编码、未正式原材料与转正式

### 5.1 正式编码不是自由文本

四类物料均需支持复制创建、大类/小类/规则辅助选择、自动填号、实时冲突提示，以及下一主体/下一版本建议。分类候选应同时显示名称和编码值，复制时同步来源规则，不只复制文字字段。

规则中固定部分不可任意改写。例如选了 `19.1XXX.0`，不能把 `10.01` 当作合法完整编码。前端提示之外，后端必须验证格式、类型和唯一性；预览通过不代表提交时仍可用。

### 5.2 `99.*` 生命周期

- 只适用于未正式原材料；不占用正式号段。
- 自动序列：`99.0001.0` → … → `99.0001.9` → `99.0002.0`，上限 `99.9999.9`，数字位宽固定。
- 后端事务取号；预览不占号，失败回滚不空占号；已成功分配后再删除也不回填，封存号仍保留。
- 从历史数据初始化后，游标不得落后于现存最大号码；不能简单从 1 重启。
- 未正式原材料可拥有合法的原材料下级，但不能作为别人的 BOM 子项或选配候选，避免草稿进入正式引用网络。
- 关键器件码为可选 `XXX.Y`，各位为字母或数字；去空白、转大写，允许重复，只提示关联物料。它不是系统物料号，也不参与正式编码取号。

### 5.3 转正式是创建，不是原地改号

重新选择正式大类、小类、规则并校验编码，创建新的正式物料与内部 ID；复制允许的档案和组成，可在提交前修改。
创建正式物料、复制组成、建立来源关系、封存原 `99.*`、双方审计必须原子完成；任一步失败全部回滚。

来源永久只读，不允许再次转正式、删除或编辑。双方可追溯，封存 BOM 可查看导出且标为历史参考，不应计入当前用量和机型归属。
新流程一条来源只能生成一条全新正式物料；不允许关联已有正式物料替代创建。旧迁移的多来源映射是历史兼容事实，不是新建规则。

## 6. 数量、比较与输出规则

### 6.1 有效用量与展开边界

示例：整机 M 使用 S 数量 2，S 的组件行数量 3，候选 A/B，占比 60%/40%，实际选 B。
生产用量是 **B = 2 × 3 = 6**，A 不计入；不是 B=2.4，也不是 A=6、B=6。

- 技术 BOM 保留路径与层级，同一个料在不同分支分别显示；行数量表示相对直接父项的用量。
- 生产用量按实际选用路径逐层相乘，使用十进制定点计算，不能用二进制浮点累计小数。
- “展开有下级组成的原材料”关闭时，原材料作为整体计量；开启时继续展开其组成。根为原材料默认开启，根为整机/单元/半成品默认关闭。
- 备用分支可展开查看，但整支都标为备用，不能混入实际用量或 BOM 比较。
- BOM 比较也要遵守相同选用和展开口径，按同类型对象比较；不能拿基础组成表代替有效 BOM。

### 6.2 网页和 Excel 刻意不同

- 网页基本信息、BOM 编辑、技术/生产 BOM 保持树形与备选行，不改成横向候选列。
- 技术/生产 Excel 和批量导出使用动态横向“选配组”列，当前选用在第一列，其余为备选；最大候选数决定列数，无配置的行留空。
- Excel 只遍历实际选用分支；备用半成品的子树不能作为主表物料行导出。
- 选配单元格内容为编码、名称及占比；仅此处名称超过 6 字符时用前 3 + `..` + 后 3 缩写，其他名称不截断。
- **生产 Excel 汇总键为实际物料 + 候选集合及其占比**：物料相同但选配不同要分行。无选配的同料可以汇总；页面生产用量仍沿用实际料汇总，移植时不要把导出分组规则误扩展到所有页面。
- 上层半成品/单元的选配放生产 Excel 的“上层选配说明”，不冒充某个原材料的直接备选，也不增加用量。
- 显示选配开关只影响呈现，不改变选用或用量；整表没有选配时不产生空候选列。
- 文件名含根物料编码和名称；技术层级有缩进/树形符号；单项与批量口径一致。叶子原材料也可导出，为自身一行。

原材料基本信息 Excel 当前为严格 13 列：序号、关键器件码、物料编码、*名称、*规格型号、*属性、*单位、备注、上一版本名称、发票名称、*材料属性、变更记录、当前在用归属产品机型。星号保留，属性对应来源；不能把旧版追溯附加列重新混入此固定模板。追溯关系仍须在数据模型和详情中保留。

## 7. 历史、删除、反向引用与机型

- 手工变更说明必须保留在追加式审计中，但不作为基本信息永久属性。日志记录操作人、时间、动作、原因、前后值和批次；新增、移除、替换自动记录组件编码名称。
- 父项变更查看需要能追到下级组成及档案变化；基本信息 Excel 的历史单元格则只汇总本档案及直接组成历史，不递归堆积全部下级日志。
- 历史必须是快照，不能只连接当前主档来还原旧值。不得因删除或重用物料编码而把旧历史挂到新对象。
- 正式物料无受保护引用时可彻底删除并释放编码；删除自身关系不删除子物料。BOM 或选配引用需要阻止并列出位置，停用父项的引用也不能悄悄忽略。
- 封存来源禁止删除；正式目标删除后保留转正式目标的历史编码、名称和已删除标记。同编码新建对象不能接上旧来源。
- 反向追溯要显示“编码 + 名称”的路径，提供直接/间接筛选，不显示读者无法理解的内部 ID 链。
- 机型是整机单一属性，多台整机可同机型；列表能按机型筛选。当前归属从试制/在用整机的实际选用路径计算、去重，备用、停用整机和封存来源不计入当前归属。
- 历史初始化按名称匹配 Y60、D60、R60、T60、G65、J60B、T65、T70 等，未匹配归其他机型；这是初始化辅助，不是把机型字段改成实时名称推断值。

## 8. 操作体验也是移植验收项

- 所有选料入口都需服务端搜索，不只过滤已加载页；短前缀如 `10.`、`17.` 必须命中全库。支持名称、规格等补全及继续加载，避免“先一直翻页才搜得到”。
- 主列表搜索选中后定位并高亮；子物料、复制、替换等搜索只影响自己的选择，不触发旧列表搜索重新定位或丢失 BOM 编辑上下文。
- 修改数量、增加组成、保存选配成功后立即刷新直接组成、有效层级树及相关信息，取消则不能提前改变数据。
- 编码链接统一快速查看弹窗，弹窗内可看档案与下级；点子项切换弹窗，另有新标签打开完整编辑页，避免原页丢失上下文。无子项原材料不重复展示空组成。
- 编辑弹窗只能取消、关闭或保存成功后退出；背景点击、Esc、复制文字或拖选不能意外关闭。只读弹窗允许背景关闭，但内部开始的拖选不能误触关闭。
- 中文显示状态、来源和操作提示；左右栏可拖动大小；选配可查看、展开和表格对比。
- 批量维护提供操作说明、原物料/父项搜索与层级选择；针对替换/删除的父项只列实际相关引用。操作前预览影响，明确确认，按批次审计。
- 列表全选当前全部筛选结果，反选仅处理已加载页；勾选跨页保留，改变筛选清空并提示。单项、已选、筛选结果导出范围要明确。

## 9. 日常导入与历史初始化必须分开

日常 Excel 是四类混合档案导入，不在同一流程偷偷创建 BOM 关系。上传先预览，问题行可修正/取消，保留行整批原子提交。

- 缺失类型默认原材料；完整指定编码冲突必须报错，不能自动换号。
- 不完整前缀按匹配规则限定范围补码，如 `10.01` 可在对应 `10.0100.0`—`10.0199.0` 范围取号；多规则需人工选择，范围用尽提示。
- 预览同批避让、不占号；提交时重新查重，自动补号可在范围内顺延，手工完整号冲突整批返回修正。
- 原材料的 `99` / `99.` / `99.*` 输入优先识别未正式，覆盖“默认正式”并明确提示，再自动取号；其他输入按导入状态判断。非原材料不能使用该号段。

## 11. 迁往其他系统时的数据映射与实施顺序

| 迁移对象 | 必须保留的内容 | 容易丢失的语义 |
| --- | --- | --- |
| 物料主档 | 类型、独立内部身份、编码/版本、状态、来源及业务字段 | 关键器件码不是唯一物料号；状态与来源独立 |
| 组成行 | 行身份、父子映射、精确数量、顺序、行备注 | 路径引用依赖行身份，不只是父子编码 |
| 路径配置 | 所属物料、整条行路径、模式、选中项、候选/占比 | 必须逐段映射行 ID，不能迁成全局替代组 |
| 未正式生命周期 | `99.*` 游标、状态、历史号、封存/正式关联 | 不回收号；正式目标删除后的快照仍保留 |
| 编码规则 | 类型、大类、小类、前缀、格式和版本语义 | 不能只迁当前最大号而丢掉分类格式 |
| 历史与来源 | 原身份、动作、前后值、说明、时间、操作者映射 | 不按可复用编码重新关联旧记录 |

建议顺序：

1. 先导入主档、代码规则与身份映射，再导入组成和顺序；未正式与封存信息同时保留。
2. 根据新组成行 ID 重写每条专属路径，迁移选中项与成员，不按名称猜测。
3. 迁移转正式关联、删除目标快照及历史；若目标平台不能导入不可变日志，建立只读历史存档并保持链接，不伪造为刚发生的新操作。
4. 实现统一有效 BOM 解析服务，使树、用量、比较、机型、导出共用选用语义，Excel 单独做布局和分组适配。
5. 以代表整机/路径逐条比较实际组件与十进制数量、备选和继承来源，不能只对比总物料数或文件能否打开。
6. 完成隔离环境验收、备份与切换演练后再启用。不要把 Git 拉取当作数据库迁移；不要用重新初始化代替普通升级。

目标平台仅支持全局替代料时，应增加“所属物料 + 路径”的扩展层。目标平台只有固定 EBOM/MBOM 两套快照时，须明确实现本系统的动态档案引用及路径覆盖；不能直接把两个名称相似的模块视为等价。

## 13. 历史规则替代与待核对边界

按时间优先使用：本轮补充修复 → 四次需求确认稿 → 三次需求确认稿 → V1.1.1 → V1.1 → 初始方案。旧文档保留决策轨迹，不应并行当作全部有效要求。

- “仅原材料可嵌套”已扩展为原材料嵌套与半成品嵌套；单元、整机仍不能同类嵌套。
- Y 前缀显示/允许临时基础编码重复已改为独立唯一 `99.*`；平台编号规则改称关键器件码。
- 全局替代组已替换为路径配置；默认不显示备选已改为默认显示。
- 软删除和正式编码永占已改为受保护彻底删除、正式编码可复用；99 序列仍不回填。
- 按来源决定原材料展开已改为按实际组成；只导入原材料已扩展为四类档案。
- 三角色已改为固定四角色；网页与 Excel 相同布局已被“仅 Excel 选配横向列”明确替代。
- 旧基本信息 Excel 的附加追溯列被当前原材料 13 列协议替代；追溯数据并未取消。

**不得把实现现状与历史预期混为一谈：** V1.1.1 确认稿曾要求封存 BOM 不阻止有效物料删除，而当前彻底删除函数按物理入向 BOM 行检查，未单独过滤封存父项。若目标系统要放行这种删除，必须先确定封存组成如何保留可读历史，避免悬空外键；本次仅记录移植风险，不擅自修改该行为。

封存也不等于完整时点快照：来源记录只读，但其引用的共享子物料主档仍可能更新。若目标项目要求任意日期整棵 BOM 原样复原，需要另外确认版本快照需求，不应声称现有审计已等价提供。
