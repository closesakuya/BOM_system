## 一、逐项验收

| 需求 | 实现与验证证据 | 结论 |
|---|---|---|
| 1. 机型与引用关系 | 整机机型字段、候选与筛选、当前/历史机型反向汇总已接入；API 用例验证 `R60` 整机经半成品引用原材料，Playwright 验证四类筛选与详情。 | 通过 |
| 2. 未正式导入原材料 | 条件唯一索引允许未正式重码，显示统一加 `Y`；禁止作为 BOM 子项和替代成员；转正式冲突与成功路径均有 API 用例。正式迁移报告对账 27 条 Y/J 原材料、10 条 BOM 改接，验证结果中未正式上级/替代引用均为 0。 | 通过 |
| 3. 搜索、筛选、选择与基本信息导出 | 服务端搜索覆盖编码、名称、规格和平台编号，名称包含优先；四类筛选、回车结果、跨页勾选、全选筛选结果、反选当前页及两种 Excel 导出已由 API 和 Playwright 覆盖。 | 通过 |
| 4. 变更说明与审计历史 | `items.change_note` 已删除，正式迁移转入 1,423 条历史审计；物料、BOM、替换、选配、规则和转正式均只写不可变审计，数据库触发器禁止更新/删除审计事件。 | 通过 |
| 5. 平台编号规则 | 原材料字段已迁移并可搜索、编辑、导入；不唯一且不参与正式编码序列。迁移用例核对历史值 `B01.A`，搜索与导出用例核对输出。 | 通过 |
| 6. 原材料 Excel 导入 | 预览行支持编辑和取消；全部保留行先校验、一次事务提交，错误行未修正时不产生部分导入；自制/外协叶子可先保存。API 原子性用例和 Playwright 实际 Excel 流程均通过。 | 通过 |
| 7. 原材料批量 BOM 导出 | 来源筛选与勾选复用列表选择模型，可批量导出技术/生产 ZIP；叶子原材料技术 BOM Excel 补根物料一行。API Excel/ZIP 用例及 Playwright 下载流程通过。 | 通过 |
| 8. 编码规则维护 | 普通编辑仅接受材料属性、说明和必填变更说明；大类、小类、前缀、格式等越权字段由接口拒绝，受控 Excel 覆盖/快照恢复保持可用。 | 通过 |
| 9. 选配替代与市场占比 | 原材料、半成品、单元同类型组可用，未正式原材料和跨层级被拒绝；占比两位小数、总和 100%，前端冻结编辑项并重分。备用原材料/半成品子树展开但不进入当前生产汇总。API 与 V1.1 Playwright 场景通过。 | 通过 |
| 10. 原材料展开开关 | 技术/生产 BOM 各自拥有“显示选配”和“展开自制/外协原材料”会话开关；根原材料与其他根物料默认值不同，重新登录清除；页面、单项 Excel 和批量 ZIP共用参数。 | 通过 |
| 11. 半成品嵌套与组合半成品 | 半成品可直接包含半成品；组合标记实时派生并可筛选；写入返回可读环路，读取有 50 层安全上限；树默认展开且可收起。API 与 Playwright 新增/筛选场景通过。 | 通过 |
| 12. 复制物料删除修复 | 仅有效上级 BOM 和有效替代组阻止删除；自身下级、复制来源和版本谱系不阻止；已删除父项不再构成引用，恢复时会列出已删除子项。API 用例覆盖删除与恢复顺序。 | 通过 |
| 13. BOM 子项替换 | 四类可维护 BOM 均提供行级替换；服务端校验正式/启用、合法层级、直接重复和环路；保持数量、顺序和行备注，不属于原组时清除组并提示；审计保存双方信息。API 和真实界面场景通过。 | 通过 |
| 14. BOM Excel 统一格式 | 技术/生产单项与批量导出共用展开结果；文件名含编码和名称，层级列有树形缩进，固定行高且不换行，包含备用标识、组名、市场占比和两个开关说明。技术/生产详细表分别为 15/14 列。 | 通过 |
| 15. 升级与迁移 | 覆盖升级前自动生成可校验备份，事务失败回滚并输出失败 JSON/XLSX；成功迁移和第二次幂等执行均验证。界面、健康接口、脚本、文档和前端包版本统一为 V1.1/1.1.0。 | 通过 |
| 16. 明确不做 | 未正式状态未扩展到其他三类；未建立机型字典页；替代组不跨层级、不使用占比计算数量；直接重复不合并；不猜测历史机型；未保留 `change_note`。 | 符合 |

## 四、发布结论

V1.1 可按 `docs/operations/安装部署.md` 覆盖部署。安装脚本会优先使用可运行的项目虚拟环境，失效时回退到 PATH 中的系统默认 Python；任一依赖安装、前端构建、初始化、升级、演示数据或数据库验证步骤失败都会中止，不会显示错误的完成提示。
