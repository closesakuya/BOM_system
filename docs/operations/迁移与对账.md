# BOM V1.1.1 历史迁移与升级对账

历史文件 `data/migration/BOM物料清单管理(1).xlsm` 仅用于一次性初始化，不是日常输入或运行依赖，迁移程序不会修改它。

## 执行方式

```powershell
# 只预检并生成报告
.\.venv\Scripts\python.exe -m backend.app.migration

# 空数据库正式导入
.\.venv\Scripts\python.exe -m backend.app.migration --apply

# 已有初始数据时先备份再重建（仅迁移演练使用）
.\.venv\Scripts\python.exe -m backend.app.migration --apply --reset

# 验证正式首版数据库
.\.venv\Scripts\python.exe -m backend.app.validation
```

上述 `backend.app.migration` 只用于数据库不存在时的一次性初始化。已有正式数据库升级到 V1.1 时执行：

```powershell
.\.venv\Scripts\python.exe -m backend.app.v1_1_migration
```

正常部署应直接运行 `scripts\install_v1.ps1`，由脚本自动完成备份、V1.1 迁移、演示数据幂等检查和最终验证。升级器可重复执行；第二次执行不应重复迁移说明、Y/J 原材料、BOM 引用或市场占比。

报告写入 `runtime/reports`。初始迁移结果：4,845 个唯一物料，56 个历史“原材料/整机”跨类型重码按已确认规则合并为原材料；9 条重复关系合并数量；48 条旧的“原材料→半成品”表达被展开到叶子原材料，最终导入 17,856 条合法 BOM 关系，无跳过项、无非法层级、无环路、无重复正式编码。

历史迁移完成后执行 `python -m backend.app.demo`，会追加独立的虚拟演示数据：24 个物料、30 条 BOM、5 个替代组。脚本在写入前后对全部非演示物料档案、BOM 关系、替代组和编码规则计算摘要；摘要或数量变化会回滚事务。当前正式库完成追加后共 4,869 个物料、17,886 条 BOM，历史部分仍为 4,845/17,856。

2026-08-13 正式重建前已生成 `runtime/backups/bom-20260813-135135-pre-v1_15-initialize.db`，迁移程序另生成 `runtime/backups/pre-migration-20260813-055143.db`，两者都可用于恢复重建前状态。

V1.1 升级报告记录：历史说明转审计数量、Y/J 原材料规范化明细、BOM 引用改接、正式编码冲突、替代成员占比初始化、外键和完整性结果。27 条历史 Y/J 原材料会去除存储前缀并标记为未正式导入，其中 10 条 BOM 引用先改接到对应正式物料；非原材料 `J00...` 不处理。

正式库已于 2026-08-21 完成 V1.1 覆盖升级：升级前备份为 `runtime/backups/bom-20260821-170639-pre-v1_1.db`，对账报告为 `runtime/reports/v1_1-migration-20260821-170639.json` 和同名 `.xlsx`。报告结果为 `status=success`、`integrity=ok`，迁移 1,423 条历史变更说明、规范化 27 条 Y/J 原材料、改接 10 条 BOM 引用并初始化 10 个替代成员占比。

## V1.1.1 未正式原材料升级

正常部署仍直接运行 `scripts\install_v1.ps1`。如只需单独执行此次数据库升级，可运行：

```powershell
.\.venv\Scripts\python.exe -m backend.app.v1_1_1_migration
```

升级器把旧字段“平台编号规则”迁移为“关键器件码”，规范化大小写和空白；再按物料内部 ID 将 27 条历史未正式原材料稳定分配为 `99.0001.0`～`99.0003.6`，保留历史物料号，封存来源并建立与已有正式物料的双向关联。下一个未正式编号为 `99.0003.7`。

正式库已于 2026-08-31 完成 V1.1.1 覆盖升级。升级前备份为 `runtime/backups/bom_v1-before-v1.1.1-20260831-111407.db`，对账报告为 `runtime/reports/v1.1.1-migration-20260831-111407.json` 和同名 `.xlsx`。结果为 `status=success`、`integrity=ok`，迁移 27 条未正式原材料、规范化 7 条关键器件码，所有外键、编号、状态和封存关联检查均为 0 异常。第二次幂等执行的结构、关键器件码和物料迁移数量均为 0。

`data/samples` 中的 11 列生产 BOM 是历史时点参考，不是当前运行输入。V1.1 当前生产 BOM 增加选配状态、替代组和市场占比，页面与 Excel 使用 14 列；数据库验证仍使用整机 `00.005.01` 检查完整展开。
