# 备份、恢复与故障处理

## 在线备份

服务运行时可安全执行 SQLite 在线备份：

```powershell
.\scripts\backup_v1.ps1 -Label daily -Retain 30
```

备份位于 `runtime/backups`，默认保留最新 30 份。可用 Windows 任务计划程序每日调用此脚本。每份备份完成后自动执行 `PRAGMA integrity_check`。

## 恢复演练

1. 停止 BOM 服务。
2. 选择 `runtime/backups` 中的 `.db` 文件。
3. 执行：

```powershell
.\scripts\restore_v1.ps1 -BackupFile runtime\backups\bom-YYYYMMDD-HHMMSS-daily.db
```

脚本只接受备份目录中的文件，恢复前会再保存当前数据库，并在复制前后执行完整性检查。恢复后重新启动服务并登录抽查物料和 BOM。

## 常见故障

- 页面空白：确认 `frontend/dist` 存在，重新执行安装脚本构建前端。
- 无法登录：检查服务日志、账户是否启用以及浏览器时间是否正确。
- 数据库锁定：确认只有一个应用实例，数据库不在共享盘，等待当前事务结束后重试。
- 完整性检查不是 `ok`：立即停止服务，不覆盖现有文件，从最近通过检查的备份恢复。
- 磁盘不足：清理旧导出/测试报告并将历史备份转移到受控存储；不要手工删除当前数据库或 WAL 文件。
