# V1.2 使用与部署

本说明覆盖三次需求；与旧手册冲突处以本说明和[确认稿](../requirements/三次需求-确认稿.md)为准。

## 配置选配

在半成品、单元或整机中打开“BOM 编辑 → 完整层级结构”，展开到需要配置的组件，点击“配置选配”。

- 继承：跟随下级自身配置；候选表可查看。
- 本路径自定义：复制当前候选、占比与选用项，可搜索添加同类型正式有效组件。作用于当前所属物料的这条路径，其上级仍可继承；其他并列所属物料不受影响。
- 本路径禁用：固定选用项，不显示备用项，也不跟随下级切换。

选中单选框仅为草稿，填写变更说明并“确认保存”后生效。数量保持原组成数量。改占比时其他项按比例重分，合计必须为 100%。备用子树只读，先切为当前项才能配置其下级。

替换或移除基础组成若影响其他专属配置，系统列出所属物料和路径，确认清除才提交；取消不改数据。“选配替代”页面现在是关系总览，可搜索、对比并定位所属 BOM。

## 导入、筛选与删除

“物料导入”支持 Excel 同表混合原材料、半成品、单元、整机；物料类型列空值默认原材料。只建档案，不从该表建立组成。编码列支持“物料编码”或“系统物料编码”；历史号三种同义列和关键器件码列均可导入。

例如规则 10.XXXX.0 下输入 `10.01` 或 `10.01XX`，自动补到 `10.0100.0` 起的可用编号。完整号不自动改；多个规则匹配时在预览中选择分类及规则。99 前缀自动识别临时原材料，重新分配 99 编号。预览不占号，提交结果是最终编码；错误行需修正或取消后整批提交。

四类列表默认隐藏停用，勾选“显示已停用”可包含停用，也能单独筛选停用。原材料增加“下级组成”筛选，与来源、状态、全选和导出共同生效。

删除为彻底删除，正式编码释放；被其他 BOM/选配引用时阻止。只删除本项及自身关系，不删除其子物料。封存的 99 来源仍不可删除。误删不能从页面恢复，只能停服后按备份恢复流程恢复数据库。

原材料基本信息按指定 13 列导出；BOM 比较默认不展开带下级的原材料。技术/生产 BOM 与批量导出默认显示选配，备用不计生产汇总。

## 部署

先停止旧服务，保留整个 `runtime` 目录。不要复制其他电脑的 `.venv` 作为运行环境。项目目录运行：

```powershell
.\scripts\install_v1.ps1
.\scripts\start_v1.ps1
```

虚拟环境不可用时，安装脚本使用 PATH 中系统默认 Python 重新创建；启动脚本也保留系统 Python 回退。安装会构建前端、升级数据库、检查演示和完整性。

升级备份：`runtime/backups/bom-v1.2-before-*.db`；报告：`runtime/reports/v1.2-migration-*.json`。V1.2 迁移不清理旧备份。若原库完整性检查失败，立即停止，先恢复可信备份，不使用跳过检查或重建空库掩盖故障。

未升级数据库不能直接启动 V1.2 服务：启动阶段只读检查版本标记，提示先安装，不会自动清空或修改旧库。

本机访问 `http://127.0.0.1:8000`；其他电脑使用服务器实际局域网 IP。`0.0.0.0` 仅为监听地址。
